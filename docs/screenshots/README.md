# 实际使用截图补充说明

本目录用于保存 DSH 中真实运行 Work Modes 的截图。首页当前用文字表格占位，图片补齐后再添加图片引用。

## 文件与配文

| 建议文件名 | 建议截取内容 | 可用配文 |
| --- | --- | --- |
| `01-role-library.png` | 角色列表、搜索分类与正文编辑区 | 在一个面板里查找角色、管理分类并编辑工作规范。 |
| `02-create-role.png` | 新建表单、继承开关、说明计数和正文 | 新建角色时选择规范模式，并粘贴完整 Markdown。 |
| `03-ai-review.png` | 已提取的草稿、分类、准备审核与确认保存 | AI 草稿经人工核对和确认后进入角色库。 |
| `04-session-binding.png` | Work Modes 展开面板、当前角色、版本和锁定状态 | 当前会话固定使用已绑定的角色版本。 |
| `05-version-history.png` | v1、v2 对照，或旧会话仍绑定 v1 的画面 | 角色更新后，新旧会话各自保留对应版本。 |
| `06-narrow-dark.png` | 窄面板中的可达操作区，采用深色主题 | 面板变窄后，列表和编辑区按可用空间排列。 |

浅色主题可以另加 `07-light-theme.png`。名称可按实际内容调整，同时更新引用路径。

## 放入首页

1. 把图片放到当前目录并提交。
2. 在仓库根目录的 README「界面预览」中，用真实图片和配文替换相应占位。
3. 在合并请求中预览，确认图片清晰、路径正确，配文与画面一致。

根目录 README 的图片写法如下。

```markdown
![角色库总览](docs/screenshots/01-role-library.png)

在一个面板里查找角色、管理分类并编辑工作规范。
```

其他 `docs` 文档中引用时，可使用 `screenshots/01-role-library.png`。

建议使用同一张合成角色卡，记录宿主版本、主题和窗口大小。截图只保留需要展示的区域，隐藏账号、令牌、私人聊天和个人文件路径。模拟会话的截图在配文中注明模拟用途，真实任务截图按实际使用情况说明。
